06 · Usage Rules
Do's and Don'ts
✓ DO
Use the provided SVGs as-is. Maintain the gradient fill and stroke on the shield. Keep minimum clear space of 1x the shield width on all sides.
✗ DON'T
Don't rotate the shield. Don't change the F to a different font. Don't remove the gradient fill (flat color loses the depth). Don't add drop shadows — the glow is built into the gradient.
✓ DO
Use the gold mark on dark backgrounds (#0A0A0F through #1A1A24). Use the dark mark on white/cream. Use white on photos or colored surfaces where gold doesn't contrast.
✗ DON'T
Don't use the gold mark on light backgrounds — the gradient disappears. Don't place on busy backgrounds without sufficient contrast. Don't use the inverted solid-gold shield as the primary mark.
✓ DO
Minimum mark size: 16px wide. For sizes below 24px, the stroke and gradient are still legible because of the Orbitron Black weight.
✗ DON'T
Don't stretch or squash the shield. Don't outline the F separately from the shield. Don't add text inside the shield other than the F.
