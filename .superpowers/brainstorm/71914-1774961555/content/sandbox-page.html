Key Design Decisions

  • Two-column layout: Left = human-readable (profile, session, callback preview). Right = raw auth data (JWT decoded with color-coded sections).
  • Banner at top: Plane separation — "You're viewing this as an end user of [App Name]." Always visible.
  • "Your app receives this" block shows the exact bridge.onStateChange payload with real data. This is the "aha" moment — the customer sees what their code will get.
  • "Show raw" toggle on the JWT reveals the base64-encoded token for copying into jwt.io or API testing tools.
  • "Log out and try again" in the footer — lets them test the full login → sandbox → logout cycle.
  • "Back to Console" returns to the Platform Console (Plane 2).
  • No sidebar, no navigation. This is a focused single-page debug tool, not a dashboard.
