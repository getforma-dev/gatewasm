Phase 1 Design: Onboarding Wizard Flow

Three steps inside the console app shell. Current console stays live — wizard is a new view mode for tenants with onboarding_completed = false.

Wizard Trigger

The tenant record gets a new boolean field: onboarding_completed (default: false). When the console loads a tenant where this is false, it renders the wizard instead of the detail view. The wizard writes onboarding_completed = true + preferred_tab to the tenant config on completion.
